<h1>Python Quiz Game</h1>


<h2>Description</h2>
This project is a little quiz game made with Python. The only objective of the project was to introduce myself to python and demostrate a little of the basic logic behind this kind of games. Equally, it functioned to provide a little introduction to basic string manipulation on Python. The game provide the user with 5 questions with options from A to D. If the user correctly answered the questions, one point will be sum. At the end of the game, the program shows how many points the user have. If the user picked the wrong answers, the game will provide the correct answer and will not sum any point.
