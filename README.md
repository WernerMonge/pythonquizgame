<h1>Python Quiz Game</h1>


<h2>Description</h2>
This project is a little quiz game made with Python. The only objective of the project was to introduce myself to python and demostrate a little of the basic logic behind this kind of games. Equally, it functioned to provide a little introduction to basic string manipulation on Python.  
<br />


<h2>Languages Used</h2>

- <b>Pyhton</b>  

<h2>Program explanation</h2>

<h3>General objective</h3>
<b>The game provide the user with 5 questions with options from A to D. If the user correctly answered the questions, one point will be sum. At the end of the game, the program shows how many points the user have. If the user picked the wrong answers, the game will provide the correct answer and will not sum any point.</b> 

<h3>Validation</h3>
<b>The program validates, that in every step of the game, the information provided by the user is correct. If the information is not valid, the program will provide a warning to the user and make the question again until the user provides a valid answer.</b>
